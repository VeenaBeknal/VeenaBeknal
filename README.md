## Featured Projects

### Supervised Machine Learning Projects

- **[Amazon Product Review Helpfulness](https://github.com/VeenaBeknal/Predicting-Amazon-Product-Review-Helpfulness)**  
  Built models to predict the helpfulness of Amazon product reviews (<a href="https://nijianmo.github.io/amazon/index.html"> Dataset </a>). Utilized NLP techniques to extract features, combined with metadata features and trained various models such as like Logistic Regression, SVM, Random Forest and XGBoost.

- **[Diabetes Prediction](https://github.com/VeenaBeknal/DiabetesPrediction)**  
  Predicted diabetes in Pima Indian women referred as "River People" using the dataset(<a href="https://www.kaggle.com/datasets/uciml/pima-indians-diabetes-database"> Dataset </a>). Explored multiple tree-based models such as Decision Trees, Random Forest, Gradient Boosting, and XGBoost. Additionally, I used SHAP values to enhance model interpretability.

- **[Solar Irradiance to Power Streetlights](https://github.com/VeenaBeknal/Solar-Irradiance-to-Sustainably-Power-Streetlights)**  
   The project focuses on creating sustainable energy solutions for powering streetlights by predicting solar energy based on historical weather data from NSRDB (<a href="https://nsrdb.nrel.gov/data-viewer"> Dataset </a>). Several regression techniques, including Linear Regression, Support Vector Regression, XGBoost and L1/L2 regression were applied. The predicted irradiance values were then converted to electricity ⚡ using a widely accepted formula/logic - this novel approach can be used to help drive sustainability goals (something I'm passionate about!). Here's a cool little <a href="https://www.youtube.com/watch?v=IVOnb03VfPs">video</a> we made about our project!.

- **[Predicting Suicidal Behavior in Teens](https://github.com/VeenaBeknal/Youth-at-Risk-Predicting-Suicidal-Behavior-in-Teens)**  
  Analyzed Youth Risk Behavior Surveillance System (YRBSS) data to predict suicide risks among teens using (<a href="https://www.cdc.gov/yrbs/data/index.html"> Dataset </a>) for the year 2021.Machine learning algorithms like Logistic Regression, Random Forest, Naïve Bayes and XG Boost were applied. Creation of "Risk score", does excellent job at quantifying an individual's suicide risk.

### Unsupervised Machine Learning Projects

- **[Social Media Listening App for Reddit Data](https://github.com/VeenaBeknal/Social-Media-Listening-for-Reddit-Posts-and-Comments)**  
  Built a social media listening app using Reddit data (<a href="https://www.kaggle.com/datasets/curiel/rtechnology-posts-and-comments/data"> Dataset </a>). The app applies Latent Dirichlet Allocation (LDA) for topic modeling, utilizing PySpark for data processing. The app is deployed using Streamlit (<a href="https://reddit-historical-listening.streamlit.app/"> Social Media Listening App</a>) and analyzes trends within the r/technology subreddit.

- **[US Climatological Data Analysis](https://github.com/VeenaBeknal/USClimatologicalDataAnalysis)**  
  The dataset was extracted from the FTP server of National Oceanic and Atmospheric Administration (NOAA) (<a href="https://www.ncei.noaa.gov/pub/data/ghcn/daily/by_year/"> Dataset </a>).
  I applied K-means clustering and attempted DBSCAN to cluster and classify weather stations with similar snow and precipitation pattern. Google Cloud Platform (GCP) was used for deploying the solution.

### Deep Learning Projects

- **[Pneumonia Classification using X-Ray images](https://github.com/VeenaBeknal/Pneumonia-Classification-using-Chest-X-Ray-images)**  
  Classified pediatric chest X-rays as "Pneumonia" or "Normal" using (<a href="https://www.kaggle.com/datasets/paultimothymooney/chest-xray-pneumonia"> Dataset </a>). Utilized deep learning models such as CNN, ResNet50, ChexNet, Ensemble techniques. Incorporated explainable AI tools like SHAP and LIME to identify contributing factors to the classifications. Explainable tries to identify which parts in the X-ray lead the models to classify the X-rays as "Pneumonia" or "Normal." This is one of the hottest research topics, as deep learning models are black box models.
